name: PDF display scope
description: Keep bundle PDF corrections separate from the loading algorithm.
---

For the bundle PDF correction, the user requested only actual member outlines,
distinct inter-bundle timbers, and the configured spacer value in the PDF note:
«nur das nötigste ich will keine grundsätzlichen änderungen».

**Why:** The user explicitly limited this work to presentation, not new bundle
formation, positioning, ordering, trip allocation, or weight calculations.

**How to apply:** Do not use further PDF refinements as permission to change the
loading algorithm. Separately request direction before widening that scope.
